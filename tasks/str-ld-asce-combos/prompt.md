- dead load D = 2,918.8
- floor live load L = 408.2 (office floors, partitions included, already reduced; the office live load is 2.40 kN/m²)
- roof live load Lr = 47.0
- snow: the balanced flat roof snow load pf gives 68.0, and the minimum snow load for low-slope roofs pm gives 97.2
- wind W = ±150 (strength level)
